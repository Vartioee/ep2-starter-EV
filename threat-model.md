# Threat model for RaspberryPi home router

> 1. What are you protecting? — the asset

- Hardware, personal files, network security, hardware miss use, work computer/data, intellectual property and other devices in the network. 

> 2. From whom, and how do they reach it? — the threat

- Bot swarms and malicious attackers, unauthorized network scans, local attackers intended or by accident (quests).

> 3. What is worth doing about it? — the response

- The Pi is set up in a way, that only internet traffic that is requested inside the network can come though and the network can't be accessed from outside LAN. Only way to get inside the network is with physicl access to the Pi through WiFi with secure password and physicaly in contact to Pi's and its admin passwords. RaspberryPi is frequently updated and scanned.
